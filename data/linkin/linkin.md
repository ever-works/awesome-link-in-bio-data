## Overview

Linkin is a customizable self-hosted link tree platform. It enables users to create their own link-in-bio page with self-hosting capabilities, serving as an open-source alternative to commercial link-in-bio services.

## Features

- Customizable link tree platform
- Self-hosted deployment
- JavaScript implementation
- Open-source alternative to commercial link-in-bio services

## Deployment

Self-hosted.
