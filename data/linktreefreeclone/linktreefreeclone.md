## Overview

LinkTreeFreeClone is a LinkTree clone built with Astro and Tailwind CSS. It provides a lightweight, open-source alternative for creating a link-in-bio page that can be self-hosted.

## Features

- Link-in-bio page clone
- Built with Astro framework
- Styled with Tailwind CSS
- Open-source and self-hostable

## Deployment

Self-hosted static site, deployable on GitHub Pages.
